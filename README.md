# Погружение

Браузерный прототип кооперативной игры про батискаф «Ковчег-7» в подлёдном океане Талассии-IV.
Версия 0.1: одиночная игра, первая локация — отмель «Подлёдный сад».

## Как запустить

**На компьютере.** Откройте `index.html` двойным щелчком. Нужен Chrome или Edge. three.js лежит в `lib/`, интернет не нужен (только для шрифтов).

**На телефоне.** Для гироскопа нужен HTTPS, поэтому проще всего выложить папку на GitHub Pages:
1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Откройте `https://<логин>.github.io/<репозиторий>/` в Chrome на Android.

## Управление

| | Телефон | Компьютер |
|---|---|---|
| Ходить / вести корабль | крестовина слева | WASD / стрелки |
| Осмотреться | свайп по экрану или «Гироскоп» | мышь с зажатой кнопкой |
| Действие | круглая кнопка | E |
| Сканировать | удерживать круглую кнопку, прицел на существе | удерживать E |
| Всплыть / погрузиться | кнопки за штурвалом | Пробел / Shift |
| Прожектор, сонар | кнопки за штурвалом | F, Q |
| Журнал | кнопка сверху | J |

## Что есть

- **Корабль:** мостик (штурвал, голостол сонара, пульт инженера), коридор с люками, лаборатория со стеклянным полом и журналом.
- **Мир:** рельеф с рифами, лёд над головой, лучи света, каустика, морской снег. Шесть мест для открытий.
- **Экосистема из шести видов, которые взаимодействуют друг с другом:**
  - светляки живут стаями и прячутся в кораллах от хищников;
  - серпохвосты охотятся на светляков, слышат сонар и таранят корабль с включённым светом;
  - фонарные вуали жалят рыб, хищники их обходят, а под куполом можно спрятать корабль;
  - скребуны пасутся на светящемся мху, мох гаснет и отрастает;
  - стеклоусты из засады ловят скребунов и рыб и присасываются к иллюминатору;
  - за ледокрылами следуют стаи.
- **Исследование:** сканирование через иллюминаторы, журнал видов и наблюдений, метки на сонаре.

**Экипажем по сети.** На компьютере в той же Wi‑Fi сети запустите `node server/server.js` (нужен Node.js 18+, без пакетов). Откройте `http://<адрес компьютера>:8787/index.html?room=КОВЧЕГ&name=Имя` на каждом телефоне. Первый в комнате — хост: его игра ведёт корабль. Остальные видят тот же корабль и тоже могут им управлять. В комнате до 5 человек. Каждому достаётся роль — пилот, сонарщик, инженер или биолог — и посты чужих ролей закрыты. Сменить роль: коснуться строки «Экипаж» на приборах. Говорить с экипажем: держать кнопку «Связь» сверху. Микрофон и AR на телефоне работают только по HTTPS, поэтому для телефонов запускайте `node server/server.js --https`. Сервер сам сделает сертификат и напечатает ссылки вида `https://192.168.…:8787/…`. Браузер один раз предупредит о сертификате: «Дополнительно» → «Перейти на сайт».

## Тесты

```
python3 tools/test.py     # логические тесты внутри игры
python3 tools/smoke.py    # смоук-тест, скриншоты ПК и телефона
node server/test.js       # сервер синхронизации
```
Нужен Python 3 и `pip install playwright && python -m playwright install chromium`.
