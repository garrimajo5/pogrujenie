# Отчёты тестирования на устройстве

Эта ветка только для отчётов, в `main` её не сливаем.
Claude на компьютере владельца собирает APK из `main`, гоняет его на эмуляторе Android и кладёт сюда отчёты.

- Одна проверка — одна папка `qa/<дата>-<что проверял>/`.
- В папке `report.md` (коммит, устройство, что работает, ошибки с шагами) и скриншоты.
- Перед работой над Unity-частью прочитай свежие отчёты. Исправленную ошибку отметь в PR ссылкой на отчёт.
