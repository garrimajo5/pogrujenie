# Погружение

Кооперативная игра про батискаф «Ковчег-7» в подлёдном океане Талассии-IV.
Делается на Unity 6 под Android (папка `unity/`). Первая локация — отмель «Подлёдный сад».

## Как поставить на телефон

APK собирает GitHub Actions (проверка «Unity») на каждую PR, которая меняет `unity/`, и после слияния в `main`.

1. На телефоне или компьютере откройте репозиторий → **Actions** → **Unity** → верхний зелёный запуск на ветке `main`.
2. Внизу страницы, в **Artifacts**, скачайте `pogrujenie-apk` (нужно войти в GitHub). Это zip, внутри `Pogrujenie.apk`.
3. Распакуйте и откройте `Pogrujenie.apk` на Android-телефоне. Chrome или «Файлы» попросят разрешить установку из этого источника — разрешите.
4. Старую версию удалять не нужно: новая ставится поверх (если Android откажет — удалите старую и поставьте снова).

Артефакт хранится 14 дней. Требования: Android 8.0+ (API 26), 64-битный ARM.

## Управление (телефон, альбомная ориентация)
- Крестовина слева — ходить, за штурвалом — вести корабль.
- Свайп по экрану — осмотреться.
- Круглая кнопка — действие у поста (люк, штурвал, шлюз, лебёдка: «Достать образец» — держать).
- За штурвалом — «Всплыть», «Вниз», прожектор.

## Разработка
- Правила и устройство проекта — `CLAUDE.md`, план — `ROADMAP.md`, изменения — `CHANGELOG.md`.
- Тесты EditMode и PlayMode и сборка APK идут в GitHub Actions («Unity», GameCI).
- Концепт-арт — `docs/concept-art/`, заказы художнику — `art/REQUESTS.md`.

## Архив: браузерный прототип
Первый прототип на three.js заморожен и лежит в `archive/web/` — образец логики для переноса в Unity.
Запуск: открыть `archive/web/index.html` в Chrome. Тесты: `python3 archive/web/tools/test.py` (нужен `playwright`).
